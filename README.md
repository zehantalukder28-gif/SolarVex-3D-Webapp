# Nova Sphere — Premium Interactive 3D Web Application

An elite, gallery-style creative frontend platform overhauling static promotional energy layouts into a high-performance, state-driven 3D application. Built using vanilla structural assets, advanced GreenSock Animation Platform (GSAP) timelines, and hardware-accelerated WebGL layers via Three.js.

👉 **Live Repository:** [https://github.com/zehantalukder28-gif/NovaSphere-3D-Webapp](https://github.com/zehantalukder28-gif/NovaSphere-3D-Webapp)

---

## 💎 Core Engineering Achievements

* **State-Driven Dynamic Filter Matrix:** Eliminated template code duplication by replacing rigid, static HTML product containers with a centralized, stateful JavaScript array engine (`projectData`). Selecting category parameters (e.g., *PV Systems*, *Energy Storage*) queries the dataset in real-time, synthetically maps clean DOM elements, and flushes layouts smoothly using staggered entry animations.
* **WebGL Solar Surface Shaders & 3D Optics:** Integrated a fluid Three.js canvas layer into the primary Hero structure. Features a true geometric 3D sphere running customized noise shaders that simulate a moving, rolling solar plasma texture. GSAP binds directly to the canvas loop to animate scale and material emission values, establishing a breathing core loop.
* **Kinetic Energy Particle Physics:** Re-engineered the core Technical Showcase using a dedicated standalone Three.js viewport. Silicon solar array models are rendered on custom axes, absorbing streams of interactive light particles that simulate high-speed electrical currents cascading down the viewport.
* **Advanced Kinetic Micro-Interactions:**
    * **Lenis Integration:** Implemented premium smooth-scrolling to establish weighted kinetic momentum across scroll-linked layout checkpoints.
    * **3D Parallax Tilt:** Layered project and showcase card layouts via interactive mouse-coordinate tracking (`rotateX`, `rotateY`) and structural CSS `translateZ(60px)` dimensional separation, lifting typography above shifting backgrounds.
    * **Magnetic Cursor Snapping:** Bound principal directional indicators and UI buttons to a responsive magnetic attraction range (`.magnetic`) utilizing high-frequency cursor tracking.
* **Multi-Page Structural Synchronizer:** Engineered a dedicated template compiler script (`update_all_pages.py`) to procedurally expand, deploy, and standardize full copy grids, interactive parameters, navigation arrays, and full curtain scene transitions across 6 deep sub-portals simultaneously.
